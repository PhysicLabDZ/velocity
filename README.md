# محاكاة تغيرات طبيعة حركة الأجسام

تطبيق ويب تفاعلي (PWA) لدراسة تغيرات سرعة المتحرك، يربط بين **التصوير المتعاقب** (Chronophotography) ومخطط السرعة.

## ما يعرضه التطبيق

- **التصوير المتعاقب:** صور متتالية لسيارة تُلتقط كل فترة زمنية ثابتة، مع سهم السرعة وقيمة المسافة بين كل صورتين (المسطرة بمقياس 8px لكل متر).
- **مخطط السرعة:** يُرسم لحظة بلحظة، وكل مرحلة بلون: أخضر (متسارعة)، أزرق (منتظمة)، أحمر (متباطئة).

## حفظ المخطط (PNG أو Word)

زر **💾 حفظ المخطط** يفتح نافذة تختار منها:

- **ما يُحفظ:** مخطط السرعة، أو المواضع المتتالية (التصوير المتعاقب).
- **جدول القيم:** جدول أفقي (الزمن / السرعة) عند لحظات التصوير أسفل مخطط السرعة، يمكن إظهاره أو إخفاؤه.
- **عدد النسخ:** نسخة واحدة، أو 9 نسخ في صفحة A4، أو أقصى عدد ممكن في صفحة A4.
- **الصيغة:** صورة PNG، أو ملف Word (.docx) تكون فيه الصور جاهزة والجدول جدول Word حقيقي قابل للتعديل.

تُحفظ النتيجة من حالة المحاكاة الحالية (ما التُقط من صور حتى تلك اللحظة)، فشغّل المحاكاة أولاً.

## السيناريوهات

- حركة متسارعة (انطلاق سيارة)
- حركة منتظمة (سرعة ثابتة)
- حركة متباطئة (فرملة حتى التوقف)
- حركة مركبة (انطلاق - ثبات - فرملة)
- تسارع ثم تباطؤ

## الإعدادات

- **سرعة العرض:** 0.5x / 1x / 1.5x / 2x
- **فترة التصوير:** 0.5 / 0.7 / 1 ثانية

تغيير السيناريو أو فترة التصوير يعيد التعيين تلقائياً.

## التشغيل

يعمل التطبيق على الهاتف والحاسوب، ويمكن تثبيته على الشاشة الرئيسية والعمل دون اتصال بعد أول فتح.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً (الواجهة والمحاكاة) |
| `manifest.json` | بيانات التثبيت (الاسم والأيقونات) |
| `sw.js` | عامل الخدمة (العمل دون اتصال) |
| `icons/` | أيقونات التطبيق |

## تحديث التطبيق

عند تعديل `index.html` غيّر قيمة `CACHE_VERSION` في `sw.js` (مثلاً `velocity-v2`) حتى يصل التحديث إلى من ثبّت التطبيق.
