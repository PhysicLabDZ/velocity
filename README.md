# محاكاة حركة الأجسام

تطبيق محاكاة تفاعلي لحركة الأجسام (تسارع، حركة منتظمة، تباطؤ)، يعرض سيارة متحركة عبر تقنية التصوير الزمني المتعاقب (Chronophotography) — التقاط صور متتالية للجسم على فترات زمنية محددة مع متجهات السرعة، إلى جانب رسم بياني حي يوضح تغيّر السرعة عبر الزمن لكل سيناريو حركة.

جزء من سلسلة محاكيات **PhysicLabDZ** التعليمية الموجهة للمنهاج الجزائري (الجيل الثاني).
